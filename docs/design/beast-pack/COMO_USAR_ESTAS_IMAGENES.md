# CÓMO USAR LAS NUEVAS IMÁGENES ROBLOX — WILDBOUND

Estas imágenes son **conceptos originales generados**, NO modelos 3D ya hechos ni screenshots de un juego ejecutado. Las referencias visuales anteriores, de estilo realista, se retiraron de esta edición.

## Para cada criatura

1. Adjuntá `<BESTIA>_ficha_modelo_ROBLOX.png`: la imagen más importante para modelado. Contiene render 3/4, vistas auxiliares y rostro.
2. Adjuntá `<BESTIA>_render_principal_ROBLOX.png`: recorte limpio y grande del diseño.
3. Adjuntá `<BESTIA>_mecanica_ROBLOX.png`: escena ilustrativa de la habilidad (la implementación debe seguir el prompt técnico).
4. Usá el prompt `02_PROMPTS_INDIVIDUALES/XX_<BESTIA>.md` y, si vas a generar 3D, el de `05_PROMPTS_MODELADO_3D/`.

## Imágenes generales

- `00_MODELOS_4_BESTIAS_ROBLOX.png`: ficha de los cuatro diseños.
- `00_MECANICAS_4_BESTIAS_ROBLOX.png`: infografía de mecánicas. **Las cifras dentro de la ilustración no son valores definitivos de balance.**

## Reglas visuales

Roblox premium low-poly estilizado, no realista: siluetas angulares, proporciones grandes, materiales mate, ojos luminosos, rigs simples, sin microdetalle. No copiar assets de otros juegos.
