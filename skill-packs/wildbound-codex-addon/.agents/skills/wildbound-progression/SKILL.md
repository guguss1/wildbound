# Progresión y contrapartidas
1. Leer `PROGRESSION.md`. Crear arbolitos cortos por ruta: exploración, supervivencia, captura y conocimiento de monstruos.
2. Una habilidad importante debe poder desbloquearse con tiempo/competencia; compras Robux opcionales no deben reemplazar aprendizaje básico.
3. Tótem: definir BENEFICIO y COSTO medibles (p.ej. pesos de raro + duplicación de peligro), duración, stack y límite.
4. Cada monstruo debe tener al menos una defensa gratuita básica y un contraobjeto desbloqueable; jamás hacer imposible una zona si un usuario no paga.
5. Mostrar comparación antes/después sin confundir peso de selección con probabilidad absoluta.
6. Testear crecimiento en dificultad con cuentas nuevas y jugadores veteranos en partidas cooperativas.
**Entregables**: tabla upgrades, curva de costes, contraestrategias y test de accesibilidad.
