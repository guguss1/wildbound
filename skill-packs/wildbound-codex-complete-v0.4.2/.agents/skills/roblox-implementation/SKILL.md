1. Leer `AGENTS.md`, `knowledge/INDEX.md` y los archivos relevantes de `knowledge/roblox-mechanics/`.
2. Localizar el lugar y scripts existentes. Preferir el MCP oficial integrado de Roblox Studio si está conectado; no inventar resultados de lectura.
3. Planear cambios mínimos: estructuras de Explorer, scripts, módulos, RemoteEvents, validación del servidor y pruebas.
4. Verificar documentación oficial de Roblox para APIs sensibles a versiones.
5. Implementar en archivos versionados si existe Rojo; si no, usar Studio MCP con respaldo o dar instrucciones claras.
6. Probar solo cuando el entorno permita playtest real. Informar errores de consola y resultado reproducible.
7. Actualizar `knowledge/DECISIONS.md` si surge una decisión arquitectónica que deba persistir.
