# Fog forest visual kit

## Objective

Bring the P0 Fog Forest closer to the approved references using an original low-poly kit, and move the egg nest within La Silueta's reach.

## Problem and why

The greybox uses plain trunks and spheres, so it does not read as the intended forest. The nest at (110, -130) is 118.85 studs from the guardian home with an 80-stud leash, so the main objective carries no encounter risk.

## Scope

- Six original props: crooked evergreen, dead tree, snapped log, root arch, ruined doorway, lantern and cage marker.
- Day and night lighting pass with path and nearest lantern legible.
- Nest moved to about (35, -99), per user decision on 2026-11-07. Geometry check: 37.7 studs from home, detectable from 18% of the patrol loop by day and 46% by night, nearest pillar 26 studs.

- References: `assets/concepts/silueta-forest/`, `docs/maps/silueta-forest-concept-v1.md`.
- Keep the 14-stud route clear. Decorations stay non-colliding, and the map stays inside 400 x 400 studs.
- No change to Silueta design, rig, gameplay parameters or the awareness cue in this feature.
- Streaming stays on and damage stays off. No publishing or monetization.
- Asset upload needs explicit user consent. Studio edits need instance and place confirmation.
- Preserve work from other agents. New files only under `assets/blender/forest-kit/` and `assets/exports/forest-kit/`.
